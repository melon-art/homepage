# 个人学术主页

第一版静态首页，当前使用明确的个人资料占位内容。

## 预览

使用浏览器打开 `index.html`，无需安装依赖或执行构建。

## 文件

- `index.html`：页面结构、样式和联系方式复制交互。
- `requirements.md`：按最新反馈同步的需求说明。

## 填写资料

在 `index.html` 中替换英文名、姓名、学历、学校、院系、专业及介绍；替换照片占位区域；在 `CONTACTS` 对象中填写电话、邮箱、微信号和三个社交主页链接。没有资料的图标只会提示待提供。

简历当前禁用，提供 PDF 后再连接真实文件并启用下载。顶部五个栏目尚未制作，保留待更新状态。不设页脚。

## 版本管理

此目录已初始化为本地 Git 仓库。GitHub 远程仓库尚未连接，也尚未推送。初始自动保存由 AI Assistant 署名，不使用用户身份。
