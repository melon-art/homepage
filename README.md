# 个人学术主页

个人学术主页静态首页，按最新上传的学术主页参考图重做视觉与响应式布局。当前个人资料、照片与 News 均为明确占位，未编造履历或动态。

## 预览

使用浏览器打开 `index.html`，无需安装依赖或执行构建。

也可以在本目录启动本地预览：`python -m http.server 8765 --bind 127.0.0.1`，在浏览器打开 `http://127.0.0.1:8765/`。开发预览服务器仅在本机运行。

## 文件

- `index.html`：页面结构、样式和联系方式复制交互。
- `requirements.md`：按最新反馈同步的需求说明。
- `PRODUCT.md`：已确认的功能与内容约束。
- `DESIGN.md`、`.impeccable/design.json`：从实际页面提取的视觉规则与设计参数。

## 填写资料

在 `index.html` 中替换英文名、姓名、学历、学校、院系、专业、研究兴趣及介绍；将照片占位区域替换为有正确替代文字的图片；在 `CONTACTS` 对象中填写电话、邮箱、微信号和三个社交主页链接。没有资料的图标只会提示待提供。复制失败时提供持续显示的可选择文本供手动复制，不触发外部跳转。

News 位于右栏介绍下方；替换真实动态时填写日期、内容和相关链接，按时间倒序排列。

简历当前禁用，提供 PDF 后再连接真实文件并启用下载。顶部五个栏目尚未制作，保留待更新状态。不设页脚。

## 布局与检查

电脑端采用大照片资料栏与右侧 About／News 阅读栏；手机端改为单栏。导航、联系图标提示、空资料反馈、复制兼容方式、复制失败恢复、键盘操作、长文字及字体放大均进行了浏览器检查。个人素材缺失仍会影响最终页面的视觉完整度。
