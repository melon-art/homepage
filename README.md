## 预览

直接用浏览器打开 `index.html`，无需安装应用依赖或构建。也可在本目录运行：

```text
python -m http.server 8765 --bind 127.0.0.1
```

在浏览器访问 `http://127.0.0.1:8765/`。Python 是可选预览工具。本地预览和 GitHub 推送均不代表公网发布。

## 主要实现

`index.html` 是首页，`settings.html` 是编辑页，`profile.js` 是共享资料脚本，`about.js` 处理 About 编辑、加粗与颜色。首页原有联系交互、页面样式与内联 SVG 保持原有组织方式。HTML 保留资料及 News 默认模板；`profile.js` 将本机编辑值同步到首页及六键 `CONTACTS`。仓库默认联系方式仍为空，未提供资料时只提示待提供；News 本轮不提供编辑。没有独立组件工程、数据库或后台。

简历未选择文件时禁用；在设置中选择 PDF 并保存后，可在当前浏览器下载该文件。实际公开简历、托管路径与线上下载仍待提供和验证。五个栏目当前只有待更新提示。News 当前为一条占位卡片，没有自动排序代码。

## 编辑主页资料

首页右上角“设置” → 基本信息 → 填写资料 → 保存。可编辑姓名、英文名、学历、学校、院系、专业、About 全文及六种联系方式；可选择、更换或移除照片和 PDF。News 保持原状。

保存后返回主页并同步；About 全部由用户填写，保留换行和空行，不再按姓名／学历等自动生成。About 正文铺满右侧内容栏，与 News 两边对齐。在设置页选中文字，可点击“加粗”“金色”、选择“文字颜色”或“清除格式”；Ctrl+B／⌘B 支持加粗，保存后保留文字样式。此前填写的介绍仍会预填；留空显示“About 内容待填写。”。文字留空恢复原占位，文件移除后恢复缺失状态。照片支持 JPG／PNG／WebP（≤1 MB），简历支持 PDF（≤2 MB），文件选择后尚需点击保存。存储满或被禁用时保留草稿及上次保存记录。

修改只保存在当前浏览器／来源，不修改文件、GitHub 或其他访客看到的内容；清除站点数据后会丢失。推荐固定使用上述本地 HTTP 地址预览。直接打开 file:// 文件时可传递 About 文字及加粗／颜色；照片和 PDF 编辑请使用本地 HTTP 预览页，避免文件来源隔离及大附件 URL。
