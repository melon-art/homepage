# 个人学术主页设计评审

日期：2026-11-02。范围：现有桌面首页，对照用户提供的两张参考图。仅评审，不修改网页。

## 核心结论

目前已经具备“第一张的色调、第二张的双栏结构”，但仍是一份个人内容尚未填入的学术主页骨架。实际需要改善的是阅读尺度、未开放入口的状态和联系图标的表达；没有证据支持推翻现有网格、增加装饰或新增内容模块。

前一轮为了追求克制而整体缩小文字，削弱了正文和辅助信息的阅读分量。这是排版调整的问题。真实照片、介绍和动态尚未提供，是另一类素材问题，不能通过虚构内容或增加卡片来填补。

## 优先问题

以下五项均为 P2：需要改进，但不是阻断当前预览的紧急故障。P0、P1 均为零。

### 1. 正文和辅助文字偏细小

- 证据：正文 14px／行高 26.6px，学校及专业 12px，News 内容 13px、日期 12px，导航 13px。两种桌面尺寸下都能读，但内容在充足空间中显得细弱。
- 影响：读者容易先看到姓名，却难以轻松扫读学术背景和动态；页面的安静气质缺少足够的阅读分量。
- 建议：正文先试 15–16px，保持约 26–28px 的行高；学校信息试 13px，News 内容试 14px。不要把所有文字等比例放大，导航可以保持紧凑。
- 对应命令：`$impeccable typeset`。
- 源码依据：`index.html:16,25,36,46–47`。

### 2. 导航的位置已改善，但“待开放”状态发现过晚

- 证据：五项默认外观像普通链接，只有悬停或键盘聚焦才显示“待更新”；实际为 `aria-disabled` 的占位入口。
- 影响：第一次访问的人会先尝试跳转，再发现栏目未开放。预留栏目符合需求，问题在于可用状态没有事先表达。
- 建议：保留五项及顺序，在导航组统一给出一处低调的“栏目待更新”说明，或采用一致且清楚的待开放样式；不必继续向左移动，也无需强行把五项拉满右栏。
- 对应命令：`$impeccable clarify`。
- 源码依据：`index.html:17–18,61–65`。

### 3. 简历入口的可见表达仍承诺下载

- 证据：按钮已禁用，可见文字仍是“下载简历”，同时保留金色下划线和下载箭头；“简历待上传”只存在于辅助名称中。
- 影响：普通视觉访问者在操作前不知道它不可用。缺少 PDF 是已知阶段状态，视觉表达应与该状态一致。
- 建议：未上传时显示“简历待上传”的轻量文字状态；真实文件到位后再恢复下载入口。不增加整条彩色按钮。
- 对应命令：`$impeccable clarify`。
- 源码依据：`index.html:39,77`。

### 4. 联系图标的辨识和动作提示不足

- 证据：小红书使用打开的书本符号；悬停提示仅为“小红书”“邮箱”等名称，未说明实际执行复制。
- 影响：书本可能被理解为阅读或出版物；社交平台图标也容易让人预期打开主页。
- 建议：保留用户要求的六个图标横排与点击复制，使用更易辨识且风格一致的平台符号，提示改成“复制邮箱”“复制小红书链接”等。未提供资料时仍明确提示，不复制占位文字。
- 对应命令：`$impeccable clarify` 或 `$impeccable polish`。
- 源码依据：`index.html:31,80–85`。

### 5. 金色小字的对比度略弱

- 证据：检测器报告金色学历文字对白底约 4.2:1、News 日期约 4.3:1，低于本次检测采用的 4.5:1 普通文字阈值。
- 影响：这些文字本来只有 12–13px，偏淡的颜色进一步削弱了阅读性。
- 建议：保留第一张参考图的柔和金色方向，仅将用于小字的金色略微加深；不用改成黑色，也不用扩大金色面积。禁用简历的颜色不重复算作活动文本缺陷。
- 对应命令：`$impeccable colorize`。
- 源码依据：`index.html:9,24,39,47`。

## 已经做对的部分

1. 两栏、顶部姓名和正文对齐关系稳定；两种桌面尺寸都没有横向溢出或重叠。
2. 色彩克制、没有无关卡片和额外栏目；无页脚、六个联系图标横排均符合需求。
3. 空联系方式会提示“待提供”，不会复制假账号；键盘焦点和复制反馈均有实现。

## 认知负荷与访问者视角

总体认知负荷低。五个中文栏目和六个联系图标不自动等于选择过载；额外理解成本集中在“图标代表什么”和“入口是否能用”。

- 首次访客：能看懂左右分工，但导航和简历的外观会让人高估完成度。
- 依赖清晰文字和键盘的访客：联系按钮有可见焦点，辅助名称存在；学校和日期的小字偏淡。未进行真实读屏器测试，不声称读屏失败。
- 验证功能的访客：缺资料的反馈诚实；不过复制失败后，“请手动复制”出现在 2.6 秒消失且不便选择的提示中，后续有真实账号时应提供稳定的选择或复制替代入口。

阅读感受由第一眼的安静、端正，进入占位内容和不可用入口后的不确定感。真实照片、介绍首句和具体动态将承担个人记忆点；不应靠装饰或虚构内容代替。

- 照片占位文字对比约 3.6:1：数值问题成立，但它是临时占位内容，优先级低。

自动规则没有决定页面是否“有 AI 感”；本次结论以参考图、真实截图、字体和交互实测共同形成。

## 应保留的设计边界

不增加页脚、论文模块、装饰卡片或头像插画；不把联系图标改为竖排文字；不再为显得克制而整体缩小字号。真实介绍和动态进入后，再判断右栏行长与照片面积，避免对空内容过度调参。
