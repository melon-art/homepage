- 目录和正文共用左侧个人资料、六类联系方式及标签目录。桌面卡片以主页实际照片宽度对齐，1440 CSS px 实测均为 290px。两页右侧留白一致，扣除滚动条后实测为桌面 96px、390 CSS px 手机 36px。手机端侧栏和正文上下排列。
