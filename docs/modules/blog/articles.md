## 3. 参考图应如何转化为设计

核心是**纵向排列的宽幅文章卡片**：大图建立文章气氛，标题与简洁元信息覆盖在图上，下方浅色区域承载摘要／分类标签，卡片之间有明确间距。

| 参考特征 | 本项目落地要求 |
| --- | --- |
| 大幅横向封面 | 单列文章列表，每张卡片跨满文章内容栏；封面裁切保留主体，桌面有张力、手机仍能辨认 |
| 封面上的标题 | 标题清晰、优先级最高；文字区用局部暗色遮罩保证对比，避免整图统一压黑；长标题可自然换行 |
| 标题下的小元信息 | 首先考虑日期，可选作者／分类；图标延续现有SVG风格，避免用装饰字符代替图标 |
| 封面下浅色内容带 | 可承载简短摘要和分类标签；使用主页浅灰／白与暖金，不复制参考站的紫色主题或人物底图 |
| 圆角与卡片节奏 | 延续主站圆角及柔和阴影，不堆叠边框、阴影和装饰；首版不加侧栏，用户追加后左侧仅放个人资料与文章标签，不复制公告等无关区域 |
| 桌面／手机 | 桌面保持宽幅构图；手机卡片单列、标题及元信息换行，不将整张桌面卡片等比例缩小 |

这些是对参考图的实现方向，**具体封面高度、标题字号和摘要长度仍需通过首版预览由用户确认**。图片中看不出的悬停、翻页和详情动画，不当作用户已经指定的要求。

沿用主站1480px内容上限及48／28／20／18px响应式边距。顶部使用现行磨砂导航、既有菜单与下划线动效，不新增另一套页眉或页脚。文字使用共享`--font-site`／`--font-body`／`--font-heading`，不要重新引入地图旧字体、远程字库或以全局选择器覆盖其他页面。

| 字段 | 建议用途 |
